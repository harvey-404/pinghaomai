# 作品介绍

## 名称

拼好麦 · 两个人都省，才值得拼

## 一句话介绍

基于麦当劳中国 MCP 的双人拼餐工具，实时查询附近门店、套餐组成和价格，只推荐两个人都比各自单点便宜的方案，并让多门店邀请共享唯一领取名额。

## 适合谁

想吃特定餐品、不想独自承担整份套餐，又愿意在同一家店、同一时间与另一人自行约定食物交接的用户。

## 三个演示重点

1. **双方都省钱**：自己拿什么、对方拿什么、两边各付多少和各省多少都能看到；参考价不完整不推荐。
2. **同一邀请，多店找一人**：发起人可以接受多家附近门店，任一门店领取成功，其他门店同步下架。
3. **少选择，也有依据**：最多三个候选，自己花多少钱优先；剩余餐品按价格、经典餐品、充实度、搭配和门店覆盖评分，公开规则，不伪造成交概率。

## MCP 的必要性

如果只有模型回答，无法保证门店可供、套餐内容和杯型价格。项目实际调用四个官方查询/试算工具，补齐饮料规格价格，并在发布和领取时重新核验。AI 也可通过拼好麦 MCP 查找和领取邀请，与网页使用同一个数据库锁。

## 演示路径

选钟楼周边三店和取餐时间 → 点麦辣鸡腿堡 → 只看双方均省钱的方案 → 发布 → 另一独立浏览器身份查附近待拼单 → 领取一家店 → 其他店不再展示 → 双方确认。

## 已实现与未实现

已实现真实门店、菜单、套餐替换、试算、双边省钱筛选、独立身份邀请、多店原子占位、双方确认及自有 MCP。

尚无正式账号、消息通知、真实下单、付款、库存担保、现场分装或取餐交接服务。平台演示中的“确认”只确认拼餐分配，不是麦当劳订单。

## 同类与独立开发

已有“套餐拼图”等拆餐工具和“麦麦现拼”等陌生人拼餐作品。本作品不主张首创宽泛场景；实现重点为双边省钱筛选、跨店唯一领取与解释清楚的实时核价流程。代码由本项目独立实现，开发使用 Codex 辅助；未申报 WorkBuddy 专项。
