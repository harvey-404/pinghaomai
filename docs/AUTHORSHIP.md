# 拼好麦：制作过程与证据说明

整理日期：2026-10-23（北京时间）。这是一份可核验的开发过程说明，不是公证、司法鉴定、法律结论或“全球首创”证明。

## 简要说明（可直接用于作品介绍）

拼好麦由开发者提出场景、收敛需求并作产品取舍，使用 Codex 辅助实现、调研、文档与验证。保留的本机会话中，用户依次提出多人套餐拆分、限定两个人、按门店与取餐时间匹配、多店发布且全局唯一领取、金额优先及双方均需省钱等要求；实现、测试和演示围绕这些要求形成。我们承认已有同类项目，做过竞品调研，不以“最早发布”或“首次发明陌生人拼餐”作为参赛主张。

本材料支持核验本项目的需求演进、公开源码版本及验证范围；它不能单独证明所有实现均无第三方权利问题，也不是全量代码相似性鉴定。第三方组件、菜单、商标与图像权利边界见 [NOTICE](../NOTICE.md)。
